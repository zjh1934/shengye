# 角色档案 · 领域内核 / 合成状态机

> **每次派活请把本档案原文附进任务说明。**

- **负责**：`core:contract`（接口与模型）、`core:domain`（分章 / 小块计划 / 断点续跑 / 任务状态机）。
- **不碰**：任何 `feature:*` UI、`platform:tts`、视觉、`02_PROGRESS.md`。
- **上岗必读**：`00_CHARTER.md`、`CONSTITUTION.md`（尤其功能保留清单「制作链路」）、`contracts/ARCHITECTURE.md`、本档案。
- **契约**：纯 Kotlin 优先，不依赖 Android；接口变更**必须**先报主对话批准。
- **必须保留的语义**：逐块落盘断点续跑、AUTO/QUEUE/VIEW 续跑、自动续跑阻断原因、队列暂停、时长上限、没开始成功、意外中断、拼接/转码中态、成品登记失败时保留小块。
- **状态词表唯一**：一处定义，禁止多套叫法（旧版有 6 套）。
- **交付物**：接口 + 实现 + 单元测试 + 「改了什么 / 踩了什么坑」。
- **验收**：主对话跑单测、核对状态词唯一、核对没有 UI 依赖。
- **已知坑**：旧版状态在 UI 层 `remember{}` 里算、页面每 2 秒重读 6 类数据；同一份进度在目录页和任务页两套说法。
- **状态词落地经验（2026-11-15 C/D 组实测）**：
  - 任务状态词放 `U.stat` 的 `title`，排队项才用 `U.stateChip('queued')`；不要拿 `stateChip('done')` 表示「已完成」（它显示的是章态「可听」）。
  - 子阶段「正在拼接 / 正在转码」只出现在 C9「看进度」的状态行，**不与 `TaskState` 并列**显示。
  - 音频成品**只在独立入口出现**（C10），绝不列进任务列表 —— 这是旧版最核心的结构错误。
  - 续跑按 §4 六种原因分卡，`title / line / action` 逐条照抄词表，不要自创文案；AUTO 用**常驻可撤销恢复条**（「已接着上次继续 · 撤销」），不是弹窗也不是 Toast。
  - 「开做之前」确认卡用 `U.kv` 列参数摘要 / 已选章节 / 预计规模 + 一个「开始制作」，替代旧版整页说明书 PRODUCE。
- **记忆策略**：不可失忆（契约最敏感）。接口一变，主对话同步更新所有受影响档案。
