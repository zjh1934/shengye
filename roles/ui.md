# 角色档案 · UI / 玻璃设计

> **每次派活请把本档案原文附进任务说明。** 你没有长期记忆，本档案就是你的记忆。

- **负责**：`design:glass`、`feature:library / book / tasks / player / mixer / settings / models` 的界面与交互。
- **不碰**：`core:*` 内部实现、`platform:native`、契约签名、`CONSTITUTION.md`、`02_PROGRESS.md`。
- **上岗必读**：`00_CHARTER.md`、`CONSTITUTION.md`、`contracts/ARCHITECTURE.md`、`02_PROGRESS.md`、本档案。
- **契约**：页面只读状态 + 发意图，不读盘、不轮询、不写死色值；视觉一律走 `design:glass` token。
- **方向基线**：`preview/index.html`（毛玻璃 + 不啰嗦 + 职责分开）。玻璃要有降级策略（Android 8.0+）。
- **交付物**：可渲染的界面代码 + 自检结果 + 「改了什么 / 踩了什么坑」。
- **验收**：主对话渲染截图、对照宪法与原型、检查是否越界碰了 core / 契约。
- **已知坑（别重踩）**：
  - 旧版：目录页一页扛十几种职责还每秒轮询导致真机卡；播放器全屏却只有音符占位块；顶栏纯抽象图标无文字；深色模式次要文字刷纯白。
  - 组件库（2026-11-15 由 C/D 组实测补入）：`U.R(inner,cls)` 只收一个 inner，多个原子必须用 `+` 拼接，不能逗号传多参；`U.segGrid` 颜色键是 `done/run/redo/wait`，不是词表枚举名；`U.stateChip` 无 `stopped`，`done` 显示「可听」而非「已完成」；`U.dlg` 内部已含 `U.dim`，直接作 body 即覆盖层；`U.stat` 的 `actions` 与 `U.dlg` 的 `buttons` 只有**第 0 位**是主按钮样式。
  - 文案：词表 §4 主按钮是「去任务页」，禁词是「去任务页看」，**一字之差极易误写**；「已选章节 / 参数摘要 / 预计规模」只能落成 `U.kv` 键值，写成句子就变说明书。
  - 骨架：`U.bar({title})` 已是页面大标题，不要再放 `U.hero` 重复同文字；`P()` 默认带一条「未在播放」占位迷你条，与 `GLASS_TOKENS.md §4` 冲突 → **除明确在播放的屏外一律传 `mini:false`**（总工程师将在三组图齐后统一改默认值）。
  - 多样态：同一模板只换按钮会被打回；续跑 6 种原因必须标题 / 正文 / 主按钮 / 卡片结构都不同。
- **记忆策略**：不可失忆。每次交回时把自己踩的坑补进本档案「已知坑」，由主对话合并。
- **交付前自查（2026-11-15 F/G 组实测）**：正文别和标题说同一件事（F4 标题「改动未保存」+ 正文「音色与参数尚未保存」= 重复，改成列变更项）；分组标题别和顶栏同名（G1 顶栏「设置」+ 分组「设置」）。
