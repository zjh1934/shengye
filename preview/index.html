毛玻璃

背景光斑 + 半透明卡 + 背景模糊 + 细边 + 柔和阴影。视觉 token 只在一处定义，深浅色各一套；低端机自动降级为半透明纯色，不影响功能。

不啰嗦

界面只剩运行状态：在做什么、第几步、百分比、还剩多少、能点什么。删掉所有「怎么念 / 怎么跑 / 改一次会怎样」的教程型文字。

职责分开

我的书 / 这一本 / 正在做 / 正在听 四个空间各管一件事；任务与音频成品不再混列，运行状态全 App 只有一处来源。

模块化

模块边界 = 角色边界 = 档案边界。改视觉只动设计系统，改合成只动内核，改一页不动其它页——后期不牵一发而动全身。

这是方向基线，不是成品。确认方向后按分工逐模块落到 Kotlin 工程 · 旧码只读保留作功能比对 · 本轮未改动任何原码
