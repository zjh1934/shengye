# 毛玻璃视觉 token（`design:glass` 唯一真源）

> 视觉只在 `:design:glass` 定义。**任何页面禁止写死色值 / 模糊半径 / 圆角 / 字重。**
> 本文件同时是 `preview/index.html` 与 `spec/` 代码绘制图的共同依据：两边用同一套变量名，保证「预览图看十之八九」成立。

## 1. 设计原则

| 原则 | 落地判据 |
|---|---|
| 层级靠玻璃，不靠边框堆叠 | 背景彩色光斑 + 半透明卡 + `backdrop-filter` + 细边 + 柔和阴影 |
| 克制 | 圆角 12–18px、字重只两档（常规 / 加粗）、不做渐变按钮、不做描边图标堆砌 |
| 深浅色都成立 | 两套 token，深色下 `--sub` 必须**有明度差**（旧版深色把 text 与 sub 都刷成纯白，是错的） |
| 毛玻璃是增强，不是前置条件 | 不支持模糊的设备必须自动降级，功能不残、层级不丢 |

## 2. Token 表

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#4F46E5` | `#A5B4FC` | 主操作 / 进度 / 选中 |
| `--accentSoft` | `#EEF0FE` | `#313C63` | 次级底 / 图标底 |
| `--good` | `#0E9F6E` | `#34D399` | 可听 / 已完成 |
| `--warn` | `#B45309` | `#FBBF24` | 制作中 / 时长上限 |
| `--bad` | `#DC2626` | `#F87171` | 失败 / 需重做 |
| `--ink` | `#1B2030` | `#FFFFFF` | 主文字 |
| `--sub` | `#6B7280` | `rgba(255,255,255,.62)` | 次要文字（**必须有明度差**） |
| `--hair` | `rgba(27,32,48,.10)` | `rgba(255,255,255,.12)` | 分隔线 / 轨道 |
| `--glass` | `rgba(255,255,255,.58)` | `rgba(24,29,48,.56)` | 卡片底 |
| `--glassEdge` | `rgba(255,255,255,.85)` | `rgba(255,255,255,.16)` | 卡片细边 |
| `--shadow` | `0 10px 26px rgba(31,38,80,.13)` | `0 12px 32px rgba(0,0,0,.46)` | 柔和阴影 |
| `--wall1/2/3` | 冷蓝 → 淡紫 → 淡青 | 近黑 → 深紫 → 深青 | 壁纸渐变 |
| `--orbA/B/C/D` | 紫 / 粉 / 蓝 / 橙 | 降饱和版本 | 背景光斑 |
| `--orbO` | `.55` | `.42` | 光斑不透明度 |
| `--tabInk` | `#8A90A6` | `rgba(255,255,255,.45)` | 未选中 tab |

**几何 / 动效**

| 项 | 值 |
|---|---|
| 卡片圆角 | 15px（弹窗 18px、设备 34–52px） |
| 模糊 | 卡片 `blur(18px) saturate(1.5)`；底部 tab / 弹窗 `blur(22–26px) saturate(1.6)`；遮罩 `blur(3px)` |
| 间距 | 卡片 padding 10–11px，卡间距 9px，内容左右 12px |
| 字号 | 主 11px / 次 10px / 大标题 16–21px / 数字环 20px（以 268px 宽设备图为基准，真机按 sp 换算） |
| 状态环 | `conic-gradient(accent var(--v), hair 0)`，只留数字，不写字 |
| 动效 | 只保留进度条、旋转、滑块；禁止弹跳、禁止大面积位移动画 |

## 3. Android 落地与降级策略（不骗自己）

苹果式 backdrop blur 在 Android 依赖硬件能力，而本项目要保 **Android 8.0+ / arm64-v8a**：

| API | 能力 | 策略 |
|---|---|---|
| 31+ (12) | `RenderEffect.createBlurEffect` | 真毛玻璃，用全套 token |
| 26–30 (8.0–11) | 无系统 blur | **降级**：`--glass` 提高不透明度到 `.88`、去掉 `backdrop-filter`、保留细边 + 阴影 + 壁纸光斑 |
| 低端机 / 省电模式 | GPU 吃紧 | 再降一级：光斑改静态渐变、关掉 saturate |

> 判据：**没有模糊也要能用、要好看**。降级只改 `design:glass` 一处，`feature:*` 零改动 —— 这正是模块化的第一个实际收益。

## 4. 四个空间的固定骨架

每一屏都由 `:design:glass` 提供同一套骨架，页面只填内容：

```
状态栏
顶栏（大标题 + 一行副标题[可选] + 右侧文字按钮；禁止纯抽象图标无文字）
内容区（玻璃卡列表 / 状态卡 / 章节行）
迷你播放条（有播放时）
底部四空间 tab：我的书 · 这一本 · 正在做 · 正在听
```

调音台 / 续跑弹窗 / 播放器全屏为**覆盖式浮层**，浮层本身用更高一级模糊与阴影表达层级。
