# 验收清单（产物验收 · 不看过程）

> 子智能体对我基本是黑盒：看不到推理链，只收到结果。**所以质量靠这份清单，不靠"看它怎么想"。**
> 每条交付由总工程师逐项打勾；任一硬项不过 → 打回，不合并进度。判据是「用户能不能把事办成 + 真机手感」，不是「静态自检绿不绿」。

## A. 结构硬项（防「牵一发动全身」）

| # | 检查 | 方法 |
|---|---|---|
| A1 | 任一 `feature:*` 不 `import` 另一个 `feature:*` | 静态扫描 import |
| A2 | 任一页面无文件 IO、无 `while(delay)` 轮询 | 扫描 `File(` / `delay(` / `LaunchedEffect` 内读盘 |
| A3 | 页面内无硬编码色值 / 圆角 / 字重 | 扫描 `Color(0x` / `.dp` 字面量 / `FontWeight` 直接量 |
| A4 | 状态词表唯一（一处定义） | 对照 `STATE_VOCAB.md` 逐字核对 |
| A5 | 删掉任一 `feature:*`，`:app` 之外仍能编译 | 模块隔离构建 |
| A6 | `core:*` 无 Android 依赖（除 `:core:data` 的 IO 例外，需登记） | 依赖扫描 |

## B. 界面硬项（防「啰嗦 / 潦草」）

| # | 检查 | 方法 |
|---|---|---|
| B1 | 界面里没有解释「原理 / 后果 / 用法 / 改一次会怎样」的教程型文字 | 逐张形态图 + 字符串清单核对 |
| B2 | 每个运行态都可见：在做什么 / 第几步 / 百分比 / 剩余 / 能否取消 | 逐张形态图核对 |
| B3 | 全 App 一根进度条、一个百分比来源；目录页与任务页同词同数 | 对照 `STATE_VOCAB.md` §0 |
| B4 | 播放器有书目 / 章节归属 / 全书位置 / 全本剩余 / 可展开队列 | 对照 E 组形态图 |
| B5 | 高频操作图标配文字（不出现纯抽象图标） | 顶栏逐屏核对 |
| B6 | 深色模式 `--sub` 与 `--ink` 有明度差 | token 检查 + 截图 |
| B7 | 危险操作确认只留「删什么 + 不可撤销」，不写连锁后果清单 | 弹窗文案核对 |
| B8 | 错误落到页面上（可重试 / 可展开），Toast 只留给轻量确认 | 交互核对 |

## C. 真机手感回归（补上旧版「该适配的不适配」那一半）

> 旧版 `STATUS.md` 自己写着「静态自检绿 ≠ 编译过 ≠ 好用」。目录页卡顿、任务页混乱、播放器潦草都是在静态自检全绿的情况下活到 1.1.43 的。下面这几条**每轮必过**，写进 CI，不写在文档里就算了。

| # | 检查 | 判据 |
|---|---|---|
| C1 | 目录页冷启动 | 首帧只渲染章节列表，无可感知卡顿；不在组合期读盘 |
| C2 | 运行状态推送 | 去掉每秒轮询，改事件驱动；后台时 CPU 无空转 |
| C3 | 任务页 / 目录页状态同源 | 同一时刻两页显示的百分比与状态词完全一致 |
| C4 | 播放器信息完整 | 见 B4 |
| C5 | 停止立即生效 | 点「停止」后状态即时变化，或如实显示「请求停止 · 正在收尾」 |
| C6 | 降级可用 | 关掉模糊（模拟 8.0–11）后层级仍清晰、功能无残缺 |

## D. 功能保留硬项（防重写丢功能）

逐条对照 `CONSTITUTION.md` 第二节打勾，至少覆盖：

- 导入 `txt / md / epub`、重新分章、阅读器与位置记忆、粘贴一段即念
- 勾章 → 逐块落盘断点续跑 → 章级拼接 → 64kbps 单声道 AAC-LC M4A → 校验后删内部 WAV
- AUTO / QUEUE / VIEW 续跑、自动续跑阻断原因、队列暂停、时长上限
- 播放队列 / 倍速 0.75–2.0× / 顺序随机循环 / 接着听 / 媒体通知
- 调音台三分类 + 滑块 + 预设 + 试听 + 未保存离开确认
- 4 份模型导入与复制进度、卸载二次确认、制作中禁导入
- 权限集合（`FOREGROUND_SERVICE*` / `POST_NOTIFICATIONS` / `SYSTEM_ALERT_WINDOW` / `WAKE_LOCK`，**无 INTERNET**）

## E. 派活 / 收活流程（每次固定动作）

```
主对话派活
  → 任务说明附：roles/对应档案 + contracts/ARCHITECTURE.md + STATE_VOCAB.md
                 + GLASS_TOKENS.md + CONSTITUTION.md 相关条款 + spec/SPEC_CONTRACT.md
  → 子智能体只在自己模块边界内干活，产物落约定路径
  → 交回：改了什么 / 自检结果 / 踩了什么坑（写回自己档案）
  → 主对话按本清单验收产物（渲染 / 自检 / 对照宪法与词表）
  → 主对话更新 02_PROGRESS.md，跑 CI / 提交
```

**子智能体不直接改 `02_PROGRESS.md`、不改契约、不改宪法。**
